# Управление провайдерами из UI: проверка, переименование, удаление, каталог у исполнителей

Дата: 2026-08-04. Статус: одобрено.

## Проблема

Вкладка «Провайдеры» показывает сохранённых провайдеров, но управлять ими нельзя:
редактирование спрятано в форму «Добавить / обновить» (совпадение имени = обновление),
проверки доступности нет, удаления и переименования нет. Первый провайдер из
`svarog init` всегда называется `local` независимо от endpoint'а — у пользователя
OpenRouter живёт под именем «local», и исправить это из UI невозможно.

Во вкладке «Исполнители» модель вводится вслепую текстом, хотя каталог `/models`
выбранного провайдера уже умеет отдаваться бэкендом.

Плюс тихий баг: при живом запуске конфиг после записи не перечитывается
(ADR-0015), бэкенд честно возвращает `restart_required: true`, а UI это
игнорирует — «Провайдер сохранён», но в списке его нет.

## Решение

### Бэкенд (`gateway/service.py`, `gateway/api.py`, `gateway/models.py`)

1. **`POST /models/providers/{name}/check`** — проверка доступности.
   Резолвит сохранённый `api_key_ref`, живьём запрашивает `/models` провайдера
   **мимо кэша каталога** (кэш хранит и отрицательные результаты с TTL —
   «Проверить» обязан отражать состояние сейчас). Ответ всегда 200:
   `ProviderCheckView {ok: bool, models_count: int | null, error: str | null}` —
   недоступность это данные проверки, а не исключение. Неизвестное имя — 404.

2. **`POST /models/providers/{name}/rename`**, тело `{new_name}`.
   Валидация new_name тем же regex, что в `add_provider`; занятое имя — 422.
   Один вызов `_write_deep`: все поля старого ключа копируются под новое имя,
   старый ключ — в `removes`, `models.default` обновляется, если указывал на
   старое имя. `api_key_ref` переносится как есть — секрет остаётся валидным,
   ключ перевводить не нужно.

3. **`DELETE /models/providers/{name}`** — удаление.
   Дефолтного (`models.default`) удалять нельзя — 422 «сначала переключите
   „по умолчанию"». Схлопывание пустой обёртки `providers:` — по образцу
   `remove_mcp` (пустой словарь парсится в None и валит валидацию).

Все три идут через `_write_deep`/существующие механизмы: валидация эффективного
конфига до записи, перечитывание только без живых запусков, сброс кэша каталога.

### Фронтенд (`web/src/screens/SettingsScreen.tsx`)

4. **Строка провайдера** — новые действия:
   - «Проверить» — инлайн-статус: «проверяем…» → «доступен · N моделей» или
     текст ошибки;
   - «Изменить» — заполняет форму ниже текущими значениями (ключ пустой =
     не менять);
   - «Переименовать» — инлайн-инпут в строке, Enter/OK отправляет;
   - «Удалить» — с confirm, скрыта у дефолтного.
   «По умолчанию» и «Модели» остаются как есть.

5. **Исполнители**: при выборе провайдера автоматически грузится его каталог
   (`GET /models/{name}`) и под полем модели появляется `CatalogList`
   с фильтром — тот же компонент, что в форме провайдеров (у OpenRouter сотни
   моделей, нативный `<select>` нечитаем). Клик подставляет модель в поле,
   поле остаётся редактируемым руками (каталог бывает неполным). Каталог
   недоступен — текст ошибки, поле работает как раньше. `claude-code` — без
   изменений (текст, провайдера нет).

6. **`restart_required`**: после сохранения/переименования/удаления провайдера
   и дефолтов исполнителей, если ответ несёт `restart_required: true`,
   показывается «Правка записана, вступит в силу после завершения текущих
   запусков» вместо безусловного «сохранено».

## Не делаем (YAGNI)

- Показ текущих дефолтов external-исполнителей (модель/провайдер сейчас не
  отдаются API — отдельная задача).
- Автопроверка всех провайдеров при открытии вкладки — лишние сетевые походы.
- Модалки/маршруты для редактирования — форма «Добавить / обновить» остаётся
  единственной точкой правки полей.

## Тесты

- pytest: три новых эндпоинта в `tests/test_gateway_providers_mcp.py` —
  check (ок и недоступный провайдер), rename (перенос полей, обновление
  default, занятое имя), delete (обычный, дефолтный — 422, последний —
  схлопывание обёртки).
- vitest (`SettingsScreen.test.tsx`): проверка/переименование/удаление из
  строки, каталог у исполнителей, сообщение про `restart_required`.
